# WEALTH QUEST

เกมการเงินแนว management/roguelite — ทรัพยากรสามอย่างที่ขัดแย้งกัน: **เงิน · เวลา (720 ชม./เดือน) · สุขภาพ**

- 📄 `WEALTH-QUEST-GDD.md` — เอกสารออกแบบฉบับเต็ม (**สร้างอัตโนมัติ อย่าแก้ด้วยมือ**)
- 🧪 `PLAYTEST-GUIDE.md` — คู่มือทดสอบกับคนนอก (เฟส 1)

## เล่นเลย

เปิด `wealth-quest-prototype.html` ด้วยเบราว์เซอร์ ไม่ต้องติดตั้งอะไร

## โครงไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `engine.js` | **ตรรกะเกมทั้งหมด ไม่มี DOM แม้แต่บรรทัดเดียว** — แหล่งอ้างอิงจริงของทุกตัวเลข |
| `ui.html` | UI ล้วน + ช่อง `/*__ENGINE__*/` ให้ inject เอนจินเข้าไป |
| `wealth-quest-prototype.html` | ไฟล์เดียวจบสำหรับแจกให้คนเล่น — **สร้างจาก build.js อย่าแก้มือ** |
| `tests/` | ชุดทดสอบถดถอย 24 ข้อ |
| `tools/build.js` | ประกอบ `ui.html` + `engine.js` → ไฟล์ที่แจก |
| `tools/reference.js` | สร้างตัวเลขสมดุลอ้างอิงแบบทำซ้ำได้ |
| `sim.js` | การจำลองรุ่นเดิม (ใช้ `Math.random` เลือกอาชีพ — ผลซ้ำไม่ได้ ใช้ `tools/reference.js` แทน) |
| `gendoc.js` · `writegdd.js` | สร้าง GDD จากตัวเลขจริงในเอนจิน |
| `godot/` | โครงพอร์ตไป Godot 4 (core เป็น GDScript แล้ว UI ยังเป็น placeholder) |

## เวิร์กโฟลว์ — ทุกครั้งที่แก้ `engine.js`

```bash
node --test "tests/*.test.js"   # 1) ต้องเขียวครบก่อน
node tools/reference.js         # 2) ดูว่าสมดุลขยับไปเท่าไหร่
node tools/build.js             # 3) ให้ไฟล์ที่คนเล่นจริงได้โค้ดใหม่ด้วย
node writegdd.js                # 4) สร้างเอกสารใหม่จากตัวเลขจริง
```

**ข้อ 3 ห้ามลืม** — เดิมไม่มีสคริปต์ประกอบ ทำให้แก้บั๊กในเอนจินแล้วไฟล์ที่ผู้เล่นเปิดจริง
ยังเป็นโค้ดเก่าอยู่ ใช้ `node tools/build.js --check` เช็กได้ว่าตรงกันหรือยัง

## กฎเหล็ก

1. **`engine.js` ห้ามรู้จัก DOM** — นี่คือสิ่งเดียวที่ทำให้จำลอง 4,000 เกมได้ใน 21 วินาที
   ถ้าพังข้อนี้ จะปรับสมดุลไม่ได้อีกเลย (GDD ข้อ 13.1)
2. **การสุ่มที่มีผลต่อเกมต้องใช้ตัวสุ่มของแมตช์เท่านั้น** ห้าม `Math.random()` ใน UI
   เพราะ state ของตัวสุ่มอยู่ในไฟล์เซฟ — ไม่งั้นผู้เล่นเซฟแล้วโหลดซ้ำเพื่อรีดผลที่ชอบได้ (GDD ข้อ 14.2)
   ใช้ `Math.random()` ได้เฉพาะแอนิเมชันลูกเต๋าและการเลือก seed ตอนเริ่มแมตช์
3. **แก้ตัวเลขสมดุลเมื่อไหร่ ต้องรัน `tools/reference.js` ทุกครั้ง** ก่อน commit

## Godot

ดู `godot/README.md` และ `godot/CLAUDE.md` — งานแรกคือตรวจว่าพอร์ตถูกต้อง:

```bash
godot --headless --script res://sim/headless_sim.gd
```

ตัวสุ่มของ GDScript ต้องให้ค่าตรงกับ JS เป๊ะ ทดสอบด้วย `makeRng(12345)` 5 ค่าแรก
(ดูค่าอ้างอิงใน `tests/rng.test.js`) ถ้าตัวสุ่มไม่ตรง ทุกอย่างจะเพี้ยนหมด
