# Wealth Quest — Godot project skeleton

เกมการเงิน 2.5D · เงิน · เวลา · สุขภาพ

## เริ่มยังไง

```bash
godot --headless --path . --import                       # ครั้งแรกเท่านั้น — สร้าง class cache
godot --headless --path . --script res://sim/rng_check.gd    # 1) ตัวสุ่มต้องตรงกับ JS ก่อน
godot --headless --path . --script res://sim/headless_sim.gd # 2) สมดุลต้องผ่าน 40–60 เดือน
godot --headless --path . --script res://sim/parity_dump.gd -- 60   # 3) ผลต้องตรงกับ engine.js ทีละเกม
godot --headless --path . --script res://sim/save_check.gd   # 4) เซฟ/โหลดต้องเก็บครบรวมถึง state ตัวสุ่ม
godot --headless --path . --script res://sim/ui_check.gd     # 5) ตรรกะวิดเจ็ต UI
godot --headless --path . --script res://sim/flow_check.gd   # 6) หน้าจอส่งไม้ต่อกัน: setup → เกม → ด่าน 2 → เซฟ/โหลด
WQ_SHOT=/tmp/ui.png godot --path .                           # ดูหน้าตาจริง: เปิด → ถ่ายภาพ → ปิดเอง
WQ_SHOT=/tmp/ui.png WQ_SHOT_SCROLL=1800 godot --path .       # เลื่อนหน้าลงก่อนถ่าย (ดูวิดเจ็ตใต้ขอบจอ)
WQ_PLACE=gym WQ_SHOT=/tmp/gym.png godot --path .             # วางผู้เล่นไว้ที่สถานที่นั้นเลย (แผงลงมือทำเปลี่ยนตามที่ยืน)
godot --headless --path . --script res://world/tools/model_lint.gd    # ตรวจโมเดลทุกชิ้น (tris · วัสดุเดียว · ฐาน y=0)
godot --headless --path . --script res://world/tools/glb_export.gd    # อบเมชต่อกล่องเป็น .glb (ไม่แตะไฟล์ที่คนปั้นมา)
godot --path . --script res://world/tools/icon_bake.gd                # อบไอคอน UI จากโมเดล — **ห้ามใส่ --headless**
godot --headless --path . --script res://sim/audio_check.gd          # 7) ระบบเสียงทั้งระบบ
godot --headless --path . --script res://audio/tools/sfx_bake.gd     # อบเสียงเป็น .wav (ไม่แตะไฟล์ที่คนทำมา)
godot --headless --path . --script res://audio/tools/sfx_readme.gd   # สร้าง audio/README.md
WQ_SFX=win godot --path .                                            # ฟังเสียงตัวเดียวแล้วปิดเอง
godot --headless --path . --script res://sim/music_check.gd        # 8) เพลงพื้นหลัง
godot --headless --path . --script res://audio/tools/music_bake.gd # อบเพลงเป็น .wav
WQ_MUSIC=crisis godot --path .                                     # ฟังเพลงตัวเดียวแล้วปิดเอง
WQ_MUTE=1 godot --path .                                             # เปิดเกมแบบไม่มีเสียง
WQ_PANEL=audio WQ_SHOT=/tmp/audio.png godot --path .                 # ถ่ายภาพแผงปรับเสียง
```

อ่าน `CLAUDE.md` (บริบทและกฎของโปรเจกต์) และ `../WEALTH-QUEST-GDD.md` (เอกสารออกแบบ)

> **ต้อง `--import` ก่อนเสมอในเครื่องใหม่** ไม่งั้น `--script` จะหา `WQData` / `WQMatch` ไม่เจอ
> เพราะ Godot ยังไม่ได้สร้าง global class cache (`.godot/global_script_class_cache.cfg`)

## บั๊กที่เจอตอนทำให้พอร์ตรันได้ครั้งแรก

| ปัญหา | สาเหตุ |
|---|---|
| ตัวสุ่มให้ค่าไม่ตรงกับ JS **เลยสักค่า** | `next()` แปลจาก JS ตกไป — JS เป็น `(t + imul(...)) ^ t` แต่พอร์ตมาเป็น `& 0xFFFFFFFF` เฉยๆ `^ t` หายไปทั้งตัว |
| `Stack underflow` ตอนรันเกมยาว | `begin_month → run_ai_turns → end_month → begin_month` เรียกซ้อนกันเดือนละชั้น เกมบอทล้วน 100+ เดือนทำ stack ล้น → แก้เป็นลูป |
| คอมไพล์ไม่ผ่าน 20 จุด | `var x := round(...)` — `round()` ของ Godot คืน Variant ต้องใช้ `roundf()` · และ `match_ref` ไม่มี type ทำให้ทุกอย่างที่อ่านผ่านมันเป็น Variant |

## บั๊กที่เจอตอนพอร์ตระบบแผนที่

ทั้งสามตัวมีมาตั้งแต่พอร์ตรอบแรก และ **ค่าเฉลี่ยของ sim จับไม่ได้เลย** — sim เดิมก็ผ่านเกณฑ์ 40–60 เดือน

| ปัญหา | สาเหตุ |
|---|---|
| ตลาดผลิตดีลคนละใบทั้งที่ตัวสุ่มยังตรง | `pick_template()` กรองด้วย `downPct[0]` แต่ JS ใช้ `downPct[1]` (เงินดาวน์จริงสุ่มได้ถึงตัวบน) |
| พื้นเงินดาวน์ของการันตี "ดีลที่คนจนที่สุดเอื้อม" ผิด | hardcode `30000` ไว้ แต่ค่าจริงจาก `data/deals.json` คือ `20000` — ตอนนี้คำนวณด้วย `WQData.cheapest_down()` |
| ภัยพิบัติลูกแรกมาคนละเดือน | คาบเริ่มต้นเป็น `9 + สุ่ม(10)` แต่ JS เป็น `9 + สุ่ม(8)` |

## หน่วยความจำ — `match_ref` ต้องเป็น WeakRef เท่านั้น

`WQMatch.players` ถือผู้เล่นไว้แบบแข็งอยู่แล้ว ถ้า `WQPlayer.match_ref` ถือกลับแบบแข็งด้วย
จะกลายเป็นวงอ้างอิง RefCounted แล้วทั้งแมตช์จะไม่ถูกคืนหน่วยความจำเลย
(เดิมรัน sim รอบเดียวรั่ว 2,884 object) ตอนนี้ `match_ref` เป็น property ที่อ่าน/เขียนผ่าน
`WeakRef` ข้างใน จุดเรียกใช้ทั้ง 31 แห่งจึงเขียนเหมือนเดิมได้ **อย่าเปลี่ยนกลับเป็นตัวแปรธรรมดา**

เจ้าของอายุจริงของแมตช์คือคนที่สร้างมัน — ถ้าเก็บ `WQMatch` ไว้ในตัวแปรชั่วคราวแล้วปล่อยหลุด
ผู้เล่นจะอ่าน `match_ref` ได้เป็น `null` sim ทุกตัวใน `sim/` ถือแมตช์ไว้ในตัวแปรของตัวเองแล้ว

รันตัวไหนใน `sim/` ก็ได้ ถ้ามีบรรทัด `ObjectDB instances were leaked at exit` โผล่มาแปลว่าวงอ้างอิงกลับมาแล้ว

## ที่ยังค้างอยู่

- **ยังไม่มี `.glb` ที่คนปั้นมาจริงสักไฟล์** — 0/38 ชิ้น ทรงของทุกชิ้นยังเป็นเมชต่อกล่องจากโค้ด
  ท่อส่งงานเดินครบวงแล้ว วางไฟล์ทับได้ทีละชิ้น (เช็กลิสต์ใน `world/models/README.md`)
- **ยังไม่มีเสียงที่คนทำจริงสักไฟล์** — 0/30 ทุกตัวเป็นคลื่นสังเคราะห์จากโค้ด
  ท่อเดินครบวงแล้ว วางไฟล์ทับได้ทีละตัว (เช็กลิสต์ใน `audio/README.md`)
- **ยังไม่มีเพลงที่คนทำจริงสักไฟล์** — 0/3 ทุกเพลงเรียบเรียงจากตารางโน้ตในโค้ด
  วางไฟล์ทับได้ทีละเพลง (เช็กลิสต์ใน `audio/README.md`)
- ยังไม่ได้ฝังฟอนต์ไทยที่มีสิทธิ์ใช้งานลงในโปรเจกต์ (ตอนนี้ยืมจากระบบผ่าน `SystemFont`)

## หมายเหตุ

โค้ด GDScript ทั้งหมดเขียนโดยแปลจาก `engine.js` ซึ่งเป็น reference implementation ที่ทดสอบแล้ว
ถ้าผลจาก sim ไม่ตรงกับตารางอ้างอิงใน `CLAUDE.md` **ให้เชื่อ `engine.js` เป็นหลัก**
