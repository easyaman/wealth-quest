# ระบบเสียง Wealth Quest — เอกสารออกแบบ

วันที่ 2026-08-20 · สถานะ: อนุมัติดีไซน์แล้ว รอทำแผนลงมือ

## ทำไมต้องมีเอกสารนี้

เสียงเป็นหนึ่งในสามอย่างที่ยังค้างอยู่ (อีกสองคือ `.glb` ที่คนปั้นจริง กับฟอนต์ไทยที่ฝังได้)
ตอนเริ่มเขียนเอกสารนี้ คำว่า `audio` / `sound` / `sfx` ไม่ปรากฏในโปรเจกต์เลยแม้แต่บรรทัดเดียว
ไม่มี autoload ไม่มี bus ไม่มีไฟล์เสียง และ `ART-DIRECTION.md` กับ GDD ก็ไม่ได้เขียนทิศทางเสียงไว้
(GDD เอ่ยคำว่า "เสียง" ครั้งเดียวในตารางเฟสบทที่ 20) — ทุกอย่างในเอกสารนี้จึงเป็นการตั้งต้นใหม่

## สี่ข้อที่เจ้าของโปรเจกต์ตัดสินแล้ว

| คำถาม | คำตอบ | เหตุผลที่เลือก |
|---|---|---|
| เสียงมาจากไหน | **สังเคราะห์จากโค้ด แล้วอบเป็น `.wav`** | ไม่ต้องเพิ่ม dependency ภายนอก ไม่มีปัญหา license และได้ท่อ "อบไฟล์จริง → คนทำเสียงวางทับทีละชิ้น" แบบเดียวกับ `.glb` ที่เดินครบวงอยู่แล้ว |
| ขอบเขต | **SFX ครบทุกเหตุการณ์ + ปุ่มปรับเสียง** | ไม่เอาเพลงพื้นหลังรอบนี้ (ค่อยเติมทีหลังได้ ดูหัวข้อ "ที่ไม่ทำรอบนี้") |
| เสียงรู้ได้ยังไงว่าเกิดอะไรขึ้น | **เพิ่มสัญญาณเดียว `acted(kind)` ใน `core/player.gd`** | ตอนนี้การกระทำสิบกว่าอย่างยิงแค่ `changed` เหมือนกันหมด แยกไม่ออก · สัญญาณเดียวครอบคลุมทุกอย่างโดยไม่ทำให้ core บวมด้วยสัญญาณสิบตัว |
| ฟังเป็นแบบไหน | **Chiptune 8-bit ชัดๆ** | เข้าชุดกับ low poly หน้าเรียบ · สังเคราะห์ง่ายที่สุด และเดาออกตรงๆ ว่า "ตั้งใจทำเสียงนี้" ไม่ใช่เสียงจริงที่ทำไม่ถึง |

## ข้อเท็จจริงที่ตรวจกับ Godot จริงแล้ว (4.7.1 บนเครื่องพัฒนา)

ตรวจด้วยโปรเจกต์ทิ้งแยกต่างหาก ไม่ได้แตะ repo:

- `AudioStreamWAV.save_to_wav()` **มีจริงและใช้ได้** — คืน `err=0` เขียนไฟล์ RIFF/WAVE ออกมาจริง
- ขนาดไฟล์: 0.15 วินาที · 22050 Hz · mono · 16-bit = 6,658 ไบต์ → เสียง 31 ตัวรวมกันประมาณ **0.5 MB**
- `--headless` ใช้ไดรเวอร์ชื่อ `Dummy` และมี `bus_count = 1` — **ไม่พัง** แค่ไม่มีเสียงออกจริง
- **ข้อควรระวัง:** ในสคริปต์ที่ `extends SceneTree` เรียก `play()` ตั้งแต่ `_init()` ไม่ได้
  (`Playback can only happen when a node is inside the scene tree`) — `sim/audio_check.gd` ต้องรอเฟรมก่อน

## ตราประทับ "อบจากโค้ด" — ต่างจากท่อ `.glb`

`glb_export.gd` ประทับตราไว้ในช่อง `copyright` ของ glTF แล้วปฏิเสธที่จะทับไฟล์ที่ไม่มีตรา
แต่ `AudioStreamWAV.save_to_wav()` เขียนแค่ chunk `fmt` กับ `data` **ไม่มีช่องใส่ metadata**

แทนที่ด้วย `audio/sfx/baked.json` = `{ "<id>": "<sha256 ของไฟล์ตอนที่อบเสร็จ>" }`

- ตอนอบ: ถ้าไฟล์มีอยู่แล้วและ sha256 **ไม่ตรง** กับที่จดไว้ แปลว่ามีคนวางไฟล์จริงทับ → **ข้ามไฟล์นั้น** และรายงาน
- `--force <id>` สั่งทับได้ตรงๆ เมื่อจงใจ
- ผลลัพธ์เท่ากับตราประทับของ `.glb`: งานคนไม่หายเพราะเผลอรันตัวอบ

## `acted(kind)` ใน `core/player.gd`

```gdscript
signal acted(kind: String)   ## การกระทำที่ทำสำเร็จแล้ว — เสียงและเอฟเฟกต์ฟังตัวนี้
```

ยิง **ท้ายเมธอดที่ทำสำเร็จเท่านั้น หลัง `changed.emit()`** และ **ห้ามยิงเมื่อคืน `_fail()`**

| เมธอด | `kind` |
|---|---|
| `travel_to` | `travel` |
| `buy_vehicle` · `buy_device` | `buy` |
| `sell_asset` | `sell` |
| `take_loan` | `loan` |
| `repay_debt` | `repay` |
| `side_job("ot")` · `side_job("freelance")` | `ot` · `freelance` |
| `scout` | `scout` |
| `study` | `study` |
| `exercise` | `gym` |
| `vacation` | `resort` |
| `rest` | `rest` |
| `set_sleep` · `set_food` | `lifestyle` |
| `claim_dream` | `dream` |
| `enter_phase2` | `phase2` |

`close_deal` ไม่ต้องเพิ่ม — มี `deal_closed(deal)` อยู่แล้วและ `vfx.gd` ใช้อยู่

**บอทต้องเงียบ:** AI เรียกเมธอดชุดเดียวกันทั้งหมด `WQAudio` จึงผูกผู้เล่นคนเดียวผ่าน `bind_player()`
แบบเดียวกับ `vfx.gd` ทำอยู่ — สัญญาณของบอทไม่มีใครฟัง

**กฎข้อ 3 ของโปรเจกต์บังคับ:** แตะ `core/` เมื่อไหร่ต้องรัน `rng_check` + `headless_sim` + `parity_dump`
ยืนยันว่า 2,400 เกมยังตรงกับ `engine.js` ทุกช่องก่อน commit สัญญาณไม่ควรขยับตัวเลขสักตัว แต่ต้องพิสูจน์ ไม่ใช่เชื่อ

## `WQAudio` — autoload ตัวแรกของโปรเจกต์

`project.godot` วันนี้ไม่มี autoload เลย การเพิ่มถือเป็นการเปลี่ยนโครง จึงเขียนเหตุผลไว้ตรงนี้:
เสียงคลิกต้องเรียกได้จากทุก widget ถ้าเป็นโหนดใน `Main.tscn` ทุกวิดเจ็ตจะต้องไต่ `get_node` ขึ้นไปหาพ่อ
ซึ่งเปราะและผิดสไตล์ที่วิดเจ็ตทุกตัวในโปรเจกต์นี้เป็นอิสระจากกัน

### สองเลน — เขียนให้อ่านออกที่จุดเรียก

| เลน | ใครยิง | เมธอด |
|---|---|---|
| **เหตุการณ์ของเกม** | สัญญาณเท่านั้น (`acted` · `deal_closed` · `month_ended` · `disaster_started` · `player_finished` · `match_over`) | ไม่มี API สาธารณะ — `ui/` สั่งยิงไม่ได้เลย เหมือนกฎของ `vfx.gd` |
| **เสียง UI ล้วน** | widget เรียกเอง ตอนคลิกปุ่ม เปิด/ปิดแผง กดไม่ได้ | `WQAudio.ui("click")` |

ชื่อเมธอดต่างกันเพื่อให้อ่านที่จุดเรียกออกทันทีว่าเป็นเลนไหน
**`ui()` ห้ามใช้กับเหตุการณ์ของเกม** — ถ้าปล่อยให้ใช้ วันหนึ่งจะมีเสียง "ปิดดีล" ดังทั้งที่ดีลยังไม่ปิด
(เงินไม่พอ เวลาไม่พอ) ซึ่งคือบั๊กแบบเดียวกับที่กฎของ `vfx.gd` กันไว้

### รายละเอียดข้างใน

- bus `Master → SFX` ใน `audio/default_bus_layout.tres` (เผื่อช่อง `Music` ไว้ทีหลัง)
- pool 8 `AudioStreamPlayer` วนใช้แบบ round-robin — เสียงซ้อนกันได้ แต่ไม่งอกโหนดไม่รู้จบ
- cooldown ต่อ id (ค่าเริ่ม 60 ms) กันเสียงรัวตอนกดปุ่มถี่ๆ
- ปิดตัวเองเงียบๆ เมื่อ `DisplayServer.get_name() == "headless"` หรือ `WQ_MUTE=1` — sim ทุกตัวต้องรันได้เหมือนเดิม
- เก็บ `played: Array[String]` เป็นประวัติการยิง ให้ `audio_check` ตรวจได้ว่าสัญญาณไหนทำให้อะไรดัง (ท่าเดียวกับ `vfx.gd`)

## สเปกเสียงใน `bank.gd`

รูปแบบเดียวกับ `SPEC` ของ `vfx.gd` — ตารางค่าคงที่ อ่านทั้งตารางเห็นทั้งเกมในหน้าจอเดียว

```gdscript
## id: [คลื่น, โน้ตเริ่ม(Hz), โน้ตจบ(Hz), ความยาว(วิ), attack, decay, ระดับเสียง]
const SPEC := {
    "click": ["square", 880.0, 880.0, 0.04, 0.002, 0.03, 0.35],
    ...
}
```

`synth.gd` รู้จักคลื่นสามแบบพอ: `square` (โทนหลักของ chiptune) · `triangle` (เสียงนุ่ม เงิน/ชนะ) ·
`noise` (เดินทาง ภัยพิบัติ ลูกเต๋า) — เพิ่มทีหลังได้ถ้าจำเป็น แต่สามแบบครอบคลุมทั้ง 31 เสียงในตารางข้างล่าง

## ปุ่มปรับเสียง

ปุ่ม 🔊 บน `ui/widgets/hud.gd` (แถวเดียวกับปุ่มบันทึก/โหลด) → `WQAudioPanel`:
สไลเดอร์ Master · สไลเดอร์ SFX · ปุ่มปิดเสียง

เก็บที่ **`user://settings.cfg`** (`ConfigFile`) **แยกจากไฟล์เซฟ** เพราะเซฟมี 6 ช่อง
ถ้าเก็บระดับเสียงในเซฟ เสียงจะเปลี่ยนไปมาทุกครั้งที่โหลดคนละช่อง เขียนลงไฟล์ทันทีที่ขยับสไลเดอร์

## ทดสอบ

`sim/audio_check.gd` (headless — ต้องรอเฟรมก่อนเล่น ดูหัวข้อข้อเท็จจริงด้านบน):

1. ทุก id ที่ตารางสัญญาณอ้างถึง มีสเปกอยู่ใน `bank.gd` จริง
2. ทุก id มีไฟล์ `audio/sfx/<id>.wav` ที่โหลดเป็น `AudioStreamWAV` ได้
3. ไม่มีไฟล์กำพร้าใน `audio/sfx/` ที่ไม่มีใครอ้างถึง
4. `acted` ยิงครบทุกเมธอดในตารางเมื่อทำสำเร็จ **และไม่ยิงเลยเมื่อคืน `_fail()`** (ทดสอบด้วยผู้เล่นที่เงินหมด/เวลาหมด)
5. การกระทำของบอทไม่ทำให้ `played` งอก
6. ปิดเสียงแล้ว `played` ต้องว่าง
7. pool ไม่โตเกิน 8 โหนดต่อให้ยิงรัว 100 ครั้ง

แล้วรันของเดิมทั้งชุดยืนยันว่าไม่มีอะไรพัง:
`rng_check` · `headless_sim` · `parity_dump` · `save_check` · `ui_check` · `flow_check` · `world_check`

**ฟังจริงทุกตัวก่อนปิดงาน:** `WQ_SFX=<id> godot --path .` เล่นเสียงนั้นแล้วปิดตัวเอง (คู่กับ `WQ_SHOT`)
บทเรียนจากรอบอบไอคอนเขียนไว้ชัดว่าตัวตรวจอัตโนมัติจับได้แค่ตัวเลข ไม่ได้จับว่า "รับรู้รู้เรื่องไหม" —
เสียงก็เหมือนกัน `audio_check` ตรวจได้แค่ว่ามีไฟล์และยิงถูกจังหวะ ไม่ได้ตรวจว่าฟังแล้วเข้าใจ

## กฎที่ต้องเพิ่มลง `godot/CLAUDE.md` เมื่อทำเสร็จ

1. เสียงของเหตุการณ์ในเกม **มาจากสัญญาณเท่านั้น** — `ui/` เรียกได้แค่ `WQAudio.ui()` ซึ่งสงวนไว้ให้เสียง UI ล้วน
2. เพิ่มเมธอดที่เปลี่ยน state ใน `core/player.gd` ต้องยิง `changed` **และ `acted(kind)`** เสมอ
3. `audio/sfx/*.wav` สร้างด้วย `sfx_bake.gd` เท่านั้น · ไฟล์ที่คนทำเสียงวางทับจะมี sha256 ไม่ตรงกับ `baked.json` และตัวอบจะไม่แตะ
4. `audio/README.md` สร้างใหม่ด้วย `sfx_readme.gd` เสมอ ห้ามแก้ด้วยมือ

## ที่ไม่ทำรอบนี้ (ตั้งใจตัดออก)

- **เพลงพื้นหลัง** — bus เผื่อช่อง `Music` ไว้แล้ว เติมทีหลังได้โดยไม่ต้องรื้ออะไร
- **เสียงตามตำแหน่งในฉาก 3D** (`AudioStreamPlayer3D`) — กล้อง orthographic มุมคงที่ ระยะทางไม่สื่ออะไรกับผู้เล่น
- **ducking / mixing ขั้นสูง** — 31 เสียงสั้นๆ ที่ไม่ทับกันนาน ยังไม่ต้องการ
- **เสียงพากย์หรือเสียงภาษาไทย** — คนละงานคนละสเกล
