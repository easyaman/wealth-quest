# world/models — สเปกและเช็กลิสต์โมเดล

> **ไฟล์นี้สร้างจากสคริปต์ ห้ามแก้ด้วยมือ**
> `godot --headless --path . --script res://world/tools/models_readme.gd`
> ตัวเลขและรายชื่อทั้งหมดอ่านจาก `data/*.json` โดยตรง

## สเปกก่อน export ทุกชิ้น

| ข้อ | ต้องเป็น | ทำไม |
|---|---|---|
| ฟอร์แมต | `.glb` (glTF binary) | Godot นำเข้าได้ตรงๆ ไม่ต้องมีไฟล์ texture แยก |
| ที่อยู่ไฟล์ | `world/models/<กลุ่ม>/<id>.glb` | โค้ดโหลดจาก id ตรงๆ ไม่มีตารางแปลงชื่อ |
| ชื่อไฟล์ | **= id ใน `data/*.json` เป๊ะ** | ผิดตัวเดียว = ของหายจากแท่นโชว์แบบเงียบๆ |
| origin | อยู่ที่ **ฐาน** (y = 0) | วางลงฉากเมืองแล้วต้องไม่ลอยและไม่จมพื้น |
| หน่วย | 1 unit = 1 เมตร · **หันหน้า +Z** | +Z คือฝั่งถนน · ของที่มีอยู่ (รถ อาคาร) หันแบบนี้หมด |
| shading | **flat** (Shade Flat, ปิด Auto Smooth) | สไตล์ทั้งเกมคือเห็นเหลี่ยมเห็นหน้า |
| วัสดุ | **ชิ้นละ 1 วัสดุ ชื่อ `flat`** | หลายวัสดุ = หลาย draw call และหลุดสไตล์ palette แผ่นเดียว |
| สี | map UV ไปที่ช่องบน `world/materials/palette.png` | เปลี่ยนสีทั้งเกมได้จาก `ui/theme/palette.gd` ไฟล์เดียว |
| texture ในไฟล์ | **อย่าฝังแผ่น palette ลงไฟล์** | Godot จะแกะออกมาเป็น `<id>_palette.png` กองข้างโมเดล และ palette จะถูกก๊อปหลายสิบชุด · เกมสวม `flat.tres` ให้ตอนโหลดอยู่แล้ว |
| bevel | ไม่มี ยกเว้นขอบใหญ่ที่จงใจ (1 ชั้น) | ขอบมนเยอะทำให้ทรงอ่านไม่ออกตอนย่อเป็นไอคอน |

## เช็กลิสต์

| สถานะ | หมายความว่า |
|---|---|
| ✅ ปั้นแล้ว | มีไฟล์ `.glb` ที่คนปั้นมาจริง — **งานอาร์ตของชิ้นนี้จบแล้ว** |
| 🟠 อบจากโค้ด | มีไฟล์ `.glb` จริงบนดิสก์ แต่อบมาจากเมชต่อกล่องด้วย `world/tools/glb_export.gd` |
| 🟡 ชั่วคราว | ยังไม่มีไฟล์ — ต่อกล่องขึ้นมาตอนรัน |
| ⬜ ยังไม่ทำ | ไม่มีอะไรเลย ใช้กล่องเปล่า |

**🟠 ยังไม่ใช่งานปั้น** — มันคือทรงเดียวกับที่โค้ดสร้าง แค่ย้ายมาเป็นไฟล์จริงเพื่อให้ท่อส่งงาน
เดินได้ครบวง (อบ → นำเข้า → ตรวจ → เห็นในเกม) คนปั้นเอาไฟล์ของตัวเองมาวางทับได้ทีละชิ้น
โดยไม่ต้องรอให้ครบ — **ตัวอบจะไม่แตะไฟล์ที่ไม่มีตราประทับของมันเด็ดขาด**
