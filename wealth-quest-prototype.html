เซฟเป็นไฟล์ในเครื่องคุณ — เอาไปเปิดต่อเครื่องไหนก็ได้ และส่งให้เพื่อนดูสถานการณ์เดียวกันได้

สิ่งที่ต้องทำเพิ่มเพื่อเปิด Online

เอนจินแยก Match (ตลาดกลาง + ลำดับตา + ภัยพิบัติ) ออกจาก Player ไว้แล้ว ย้าย Match ขึ้นเซิร์ฟเวอร์ได้เลย
1. Authoritative server — ห้ามให้ client คำนวณเงินเอง ไม่งั้นแก้ตัวเลขใน DevTools ได้ใน 5 วินาที
2. client ส่งแค่ action → เซิร์ฟเวอร์ตรวจสิทธิ์ → broadcast state กลับ
3. WebSocket + ห้อง + lobby + reconnect
4. นาฬิกาจับตา 60–90 วินาที หมดเวลา auto-pass
5. บอทเสียบแทนคนที่หลุด (โค้ด AI เขียนเสร็จแล้ว)
6. ฐานข้อมูลผู้เล่น สถิติ ranking ประจำซีซัน
ประเมิน 3–5 สัปดาห์สำหรับคนเดียว ถ้า core loop นิ่งแล้ว

บทเรียนที่เกมนี้สอน

• 720 ชม./เดือน เท่ากันทุกคน — หมอมีเงินเยอะสุดแต่เหลือเวลาว่างน้อยสุด

• อาหารมีสามมิติ เงิน/เวลา/สุขภาพ — ไม่มีตัวเลือกไหนดีทุกด้าน

• งานเสริมคือกับดัก 30 ชม. ได้เงินก้อนเดียว แต่ 18 ชม. ซื้อทรัพย์สินได้เงินทุกเดือน
• รถไม่ใช่ของฟุ่มเฟือยเสมอไป ถ้าเดินทางเยอะ มันคือการซื้อเวลาคืน
• ภัยพิบัติมาเป็นระยะ คนที่กู้เยอะเจ็บที่สุดตอนดอกเบี้ยพุ่ง
