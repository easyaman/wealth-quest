## เพลงพื้นหลัง

เพลงไม่ได้สร้างจากโค้ด — **มันคือช่องว่างที่รอไฟล์จากคนทำเพลง**
วางไฟล์ลง `audio/music/` ตั้งชื่อตามช่อง แล้ว `godot --headless --path . --import`
เกมจะเล่นให้เองทันทีโดยไม่ต้องแก้โค้ด · ช่องที่ยังว่างจะยืมไฟล์ของช่องอื่นไปก่อน
(ส่งมาไฟล์เดียวก็ได้ยินทั้งเกม) · ไม่มีไฟล์เลย = เกมเงียบ ไม่มี error

|---|---|---|
| `crisis` | สุขภาพต่ำกว่าเกณฑ์วิกฤต หรือมีภัยพิบัติค้างอยู่ | ⬜ ยังว่าง |
| `phase1` | ด่าน 1 หรือยังไม่เริ่มแมตช์ | ⬜ ยังว่าง |

## สเปกสำหรับคนทำเสียงสั้น

- mono · 22050 Hz ขึ้นไป · 16-bit PCM `.wav`
- ยาวไม่เกิน 2 วินาที (เสียงชนะยาวสุดที่ 1.2 วินาที)
- ชื่อไฟล์ = id ในตารางเสียงสั้นข้างบนเป๊ะ
- ทำให้ดังพอๆ กับไฟล์ที่อบไว้ ระบบไม่มี normalize ให้

## สเปกสำหรับคนทำเพลง

- นามสกุลที่ใช้ได้: `ogg · mp3 · wav` — **Godot นำเข้า `.mp4` ไม่ได้**
  แปลงก่อนด้วย `ffmpeg -i เพลง.mp4 -vn -c:a libvorbis เพลง.ogg`
- ชื่อไฟล์ = ชื่อช่องในตารางข้างบนเป๊ะ (เช่น `phase1.ogg`)
- **ลูปได้ไม่มีรอยต่อ** — ต้นเพลงต่อท้ายเพลงต้องไร้รอยสะดุด เพราะเพลงเล่นวนตลอดด่าน
  (ระบบตั้งจุดลูปให้เองที่หัวและท้ายไฟล์ ไม่มีการตัดเงียบให้)
- ความยาวเท่าไหร่ก็ได้ แต่ยิ่งยาวยิ่งไม่น่าเบื่อ — เพลงหนึ่งดังอยู่ได้หลายสิบเดือนในเกม
- ทำให้ดังพอๆ กันทุกช่อง ระบบไม่มี normalize ให้ · ผู้เล่นปรับระดับเพลงแยกจากเสียงเอฟเฟกต์ได้
